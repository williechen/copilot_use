```text
每日並行處理兩項工作，分開記錄：

一、教學：依 Chat → Pet → Analytics，各交付一個可操作功能的 Red／完整 Green／必要局部 Refactor與直接相關測試。先讀 williechen/copilot_use/main 的 docs/COMMON_LEARNING_RULES.md、需求、架構、即時進度、manifest、入口與上一篇；依 next_day選題，核對兩庫精確SHA及當日官方穩定版本。每案獨立提交、全文讀回並保存blob／SHA256後，才條件同步進度、manifest、七首頁與入口。

只寫 copilot_use/main 的教學、工程文件與證據；williechen/rust_ai_ring唯讀，產品由使用者套用。不建立第二套產品，保留已發布文章與有效斷言。預期／實際／未執行如實分列；一項受阻不漏做其餘項。FIFO依共用規則，不更新last_full_comparison。
```
