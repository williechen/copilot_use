### 完整最小 Green

在 <code>crates/ui/src/lib.rs</code> 的現有 <code>refreshed_room_list</code> <b>後方</b>新增 helper。保留原有函式（其他 Day19 tests 仍會使用），不可只換一個無呼叫者的測試 helper：

```rs
fn refresh_result_view(
    previous: Vec<(String, String)>,
    previous_query: String,
    result: Result<Vec<(String, String)>, String>,
) -> (Vec<(String, String)>, String, String) {
    match result {
        Ok(next) => {
            let status = if next.is_empty() { "尚無房間" }
                         else { "請選擇房間" };
            (next, String::new(), status.to_owned())
        }
        Err(error) => (previous, previous_query, format!("{error}，請重試")),
    }
}
```

在現有 <code>#[component] fn RoomList()</code> 的第二個按鈕「讀取／重新整理房間」之 <code>#[cfg(target_arch = "wasm32")]</code> async 區塊，只把這一段：

```rs
let previous = rows.get_untracked();
let result = room_api::list_rooms().await;
let (next_rows, next_status) = refreshed_room_list(previous, result);
set_rows.set(next_rows);
set_status.set(next_status);
set_loading.set(false);
```

<b>完整替換</b>成下面一段；其餘 RoomList 保持不變：

```rs
let previous = rows.get_untracked();
let previous_query = query.get_untracked();
let result = room_api::list_rooms().await;
let (next_rows, next_query, next_status) =
    refresh_result_view(previous, previous_query, result);
set_rows.set(next_rows);
set_query.set(next_query);
set_status.set(next_status);
set_loading.set(false);
```

這是完整最小變更（新增純 helper＋既有事件呼叫端＋兩個測試），不是要求重建整個 RoomList。原 <code>prop:value=move || query.get()</code> 與 <code>filter_rooms(&rows.get(), &query.get())</code> 原封不動，透過成功清空 query 讓全部 rows 顯示。失敗分支保留 query 和 rows；並沿用 Day19 的載入互斥。成功空陣列清空舊清單。
