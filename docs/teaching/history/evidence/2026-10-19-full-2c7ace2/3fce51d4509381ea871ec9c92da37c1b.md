### 最小 Green
在 apps/stats_server/src/[admin.rs](http://admin.rs) 的 Session 定義後加入：
```rust
// 已驗證的人員操作會延長閒置期限；不更動來源服務 token。
fn touch_session(session: &mut Session, now: Instant) {
    session.expires = now + TTL;
}
```
將現有 csrf_for 完整替換：
```rust
fn csrf_for(state: &Admin, headers: &HeaderMap) -> Option<String> {
    let key = cookie_key(headers)?;
    let now = Instant::now();
    let mut sessions = state.sessions.lock().ok()?;
    // 先移除逾時工作階段，不能讓過期 session 藉由存取復活。
    sessions.retain(|_, session| session.expires > now);
    let session = sessions.get_mut(&key)?;
    touch_session(session, now);
    Some(session.csrf.clone())
}
```
入口 GET /dashboard、GET /api/v1/events/\{source\}/summary → csrf_for → cookie_key → Session → pg_store；POST /logout 仍需 origin/CSRF 驗證。注意：目前登入時 cookie 設定 Max-Age=1800，僅延長伺服器端 Session 並不足以實現完整滑動閒置登入；**瀏覽器 cookie 仍可能在 30 分鐘後到期**。此切片屬伺服器端最小 Green，下一步須在受保護回應同步刷新 cookie、處理閒置期限後台設定，才算完整端到端驗收。
