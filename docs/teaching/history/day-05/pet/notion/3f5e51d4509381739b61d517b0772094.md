mod day5_codec_tests {

    fn rejects_invalid_json() {

    }

Green 最小實作（同檔、<code>PetProfile</code> 現有實作後）：

```rs
#[derive(Debug, thiserror::Error)]
pub enum ProfileCodecError {
    #[error("invalid profile: {0}")]
    Invalid(#[from] ProfileError),
    #[error("json codec error: {0}")]
    Json(#[from] serde_json::Error),
}

pub fn decode_profile(input: &str) -> Result<PetProfile, ProfileCodecError> {
    let profile: PetProfile = serde_json::from_str(input)?;
    profile.validate()?;
    Ok(profile)
}

pub fn encode_profile(profile: &PetProfile) -> Result<String, ProfileCodecError> {
    profile.validate()?;
    Ok(serde_json::to_string_pretty(profile)?)
}
```

若 <code>crates/pet_domain/Cargo.toml</code> 尚無 <code>serde_json</code>，加入 <code>serde_json.workspace = true</code>（根 workspace 已宣告）；這是本 Day 唯一依賴接線，須由使用者在工作分支執行，GitHub main 保持唯讀。未知鍵目前 serde 預設容忍；未來 schema 版本化與嚴格策略另開 Day，避免意外破壞向後相容。
