Green：新增純函式：

```rs
// 事件類型長度以 UTF-8 位元組計算，避免儲存層限制不一致。
fn valid_event_type(value: &str) -> bool {
    let value = value.trim();
    !value.is_empty() && value.len() <= 128
}
```
