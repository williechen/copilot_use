```rs
fn typing_event_for_room(
    connection_room: &str,
    event_room: &str,
    active: bool,
) -> Option<ServerEvent> {
    room_matches_connection(connection_room, event_room).then(|| {
        ServerEvent::TypingChanged {
            room_id: connection_room.to_owned(),
            active,
        }
    })
}
```

在既有 <code>handle_client_event</code> 中<b>只替換</b>原本忽略 <code>Typing</code> 的 match arm：

```rs
ClientEvent::Typing { room_id, active } => {
    match typing_event_for_room(&event_room_id, &room_id, active) {
        Some(event) => {
            // 共用既有 RoomHub，不產生 SQLite 訊息紀錄。
            state.room_hub.publish(event_room_id, event);
        }
        None => {
            send_event(
                socket,
                ServerEvent::Error {
                    code: "room_mismatch".into(),
                    message: "typing room does not match connection room".into(),
                },
            )
            .await?;
        }
    }
}
```

既有 <code>RoomHub::subscribe</code> 在 <code>handle_socket</code> 內會將同房間事件傳給該房間訂閱者；沒有新增未使用 Adapter。

### Refactor 與安全界線

- 保留既有 <code>room_matches_connection</code>；只使用連線路徑中的 room ID 作為廣播目標，拒絕跨房間偽造。
- 當前 Hub 包含發送端訂閱者，UI 若不想顯示自己的 typing，須於後續具備可靠 connection identity 時處理；不可捏造 user ID。
- 本功能只提供短暫訊號，沒有 disconnect 清除、超時 TTL、session／ACL、跨程序 fan-out 或重連恢復；這些留在 <code>FUTURE_WORK.md</code> 原項目，不標完成。
