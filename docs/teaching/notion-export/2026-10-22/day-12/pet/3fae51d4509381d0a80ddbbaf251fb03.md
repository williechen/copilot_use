### 最小 Green：接上既有原生視窗漫遊

在 <code>apps/desktop_pet/src/lib.rs</code> 的 <code>application</code> 之前加入：

```rs
// 只接受明確的 true 或 1；其他值均維持不移動。
fn roam_enabled_value(value: Option<&str>) -> bool {
    matches!(value, Some("true" | "1"))
}
fn roam_enabled() -> bool {
    let value = std::env::var("PET_ENABLE_ROAM").ok();
    roam_enabled_value(value.as_deref())
}
```

在 <code>application().setup(|app| { ... })</code> 中，<b>只替換</b>原本無條件 spawn 的片段：

```rs
if roam_enabled() {
    let app_handle = app.handle().clone();
    tauri::async_runtime::spawn(async move {
        roam_desktop(app_handle).await;
    });
}
```

不修改 <code>roam.rs</code> 的 <code>bounded_next_position</code>、<code>set_position</code> 或原有 stall 處理。啟用方式：啟動 Tauri 程序前設定 <code>PET_ENABLE_ROAM=1</code>；不設定則視窗保持由 OS／使用者控制。

### Refactor／限制

- <code>roam_enabled_value</code> 為純函式，測試不需修改程序環境變數，避免測試間競爭。
- 不允許 GUI 默認啟動就自行移動；目前僅啟動時讀取一次，執行中切換及每隻寵物獨立偏好尚未實作。
- 此變更不涉及掃描檔案、刪除、憑證或 SQLite；原有 FileOrganizer 授權根與唯讀預覽規則保持不變。
