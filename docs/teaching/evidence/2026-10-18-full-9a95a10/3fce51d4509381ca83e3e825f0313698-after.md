### Red
在 apps/desktop_pet/src/[roam.rs](http://roam.rs) 現有 tests 模組加入下列標籤契約測試，**先寫測試**，舊程式未提供此函式所以編譯失敗（預期 Red；非 runtime 測試失敗）。
```rust
#[test]
fn roaming_targets_pet_not_control() {
    assert_eq!(super::roaming_window_label(), "pet");
    assert_ne!(super::roaming_window_label(), "main");
}
```
### 最小 Green
在 apps/desktop_pet/src/[roam.rs](http://roam.rs) 常數區加入：
```rust
// 生活窗才允許漫遊；main 是控制窗，不能被移動。
const PET_WINDOW_LABEL: &str = "pet";
fn roaming_window_label() -> &'static str { PET_WINDOW_LABEL }
```
將原檔 roam_desktop 中下列片段：
```rust
let window = match app.get_webview_window("main") {
    Some(window) => window,
    None => {
        println!("desktop roaming unavailable: main window not found");
        break;
    }
};
```
完整替換為：
```rust
let window = match app.get_webview_window(roaming_window_label()) {
    Some(window) => window,
    None => {
        // 沒有生活窗時停止漫遊，絕不退回移動 main 控制窗。
        eprintln!("desktop roaming unavailable: pet window not found");
        break;
    }
};
```
其餘既有 bounded_next_position、[monitor.work](http://monitor.work)_area、set_position、stall detection、sleep 保留不變。這一切片只修正視窗選擇；**必須先確認實際建立的生活窗 label 確實是 pet**，若實際標籤不同，應採用建立窗的真實標籤而非硬寫 pet。發布時尚未取得建窗端完整契約；本次已核對 tauri.conf.json 並驗證原生座標，當前結果詳 Day18。完整手動 GUI 仍未通過。
