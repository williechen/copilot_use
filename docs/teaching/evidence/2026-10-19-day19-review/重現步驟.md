在獨立下載的 `williechen/rust_ai_chat` 副本進行，不對正在使用的工作目錄直接套 patch。基底必須是 `f692c2ebe7b414fe49858c1ab1c4a33ce7c3dfee`。本包不包含依賴建置產物。

1. 先確認 `git rev-parse HEAD` 與基底相同，`git status --porcelain` 為空。
2. `git apply --check /path/to/day19-review/red-tests.patch`，再套用該 patch。
3. 執行下列 Red 命令。Chat、Pet 預期缺 helper 的編譯失敗；Analytics 預期兩項行為斷言失敗。環境／依賴錯誤不能當作 Red 成功。

5. 執行同樣 day19 命令作 Green，另跑回歸與 WASM check。原始來源的 SSR 既有提示斷言失敗會保留，不能把它當成本日引入。

```sh
cargo test --locked -p ui --features ssr day19
cargo test --locked -p desktop-pet day19
```

本輪所有 cargo 命令設定 `CARGO_PROFILE_DEV_DEBUG=0 CARGO_PROFILE_TEST_DEBUG=0 CARGO_INCREMENTAL=0`，Pet／Green 設定 `CARGO_BUILD_JOBS=1`，`CARGO_TARGET_DIR` 指向本次 work/target；省去 debug symbols 與 incremental 產物，未改 features 或 lock。實際完整原始輸出位於 evidence/。

`source/` 是套完整 Green 後三個檔案的全文，可用於查看修改結果。`corrected.patch` 使用 `git diff --ignore-space-at-eol` 產出，只包含實際修改，避免 Chat 原始 CRLF 造成整檔換行差異；以 patch 套用及編譯結果為準。
