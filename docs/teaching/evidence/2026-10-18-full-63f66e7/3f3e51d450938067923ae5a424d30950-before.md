## 1. 專案大綱與操作主線
建立可啟動、互動與持久保存設定的桌面寵物，再逐步提供受控的檔案整理、學習記憶及 AI 協作。
基本主線：啟動寵物 → 即時調整互動／設定 → 保存設定與記憶 → 授權目錄 → 掃描／SHA256 預覽 → 確認或取消 → 受控操作 → 成功收據／還原 → Analytics 紀錄。每段可跨 Day 完成；確認預覽與實際檔案操作分別判定。

### Pet：多寵物、出入籠與活動
- 控制窗有多隻寵物清單，每隻各有獨立狀態、設定與生活窗，可同時出籠；狀態同步以寵物識別分流，不將所有寵物共用一份狀態。
- 「回籠子」關閉該隻生活窗、停止活動，保留資料與設定，不刪除也不影響其他寵物；直接關生活窗等同回籠子。只有出籠寵物會活動。啟動時僅預設寵物自動出籠，可預設多隻；回籠不取消預設資格。
- 關閉控制窗不停止已出籠寵物；重開只顯示並聚焦既有控制窗。已出籠者再按出籠只聚焦自己的既有生活窗。
- 右鍵提供「開啟控制窗」「回籠子」「坐下」；開啟控制窗時自動選取自己；坐下等同關閉該隻漫遊。
- 控制窗與寵物生活窗皆可手動拖曳，自動漫遊只移動寵物，不移動控制窗。拖曳寵物時暫停漫遊，放開依原開關恢復；漫遊開關逐隻持久保存，重啟沿用。
- 走、跑、睡、跳依種類習性自然交替，不提供使用者固定速度設定。關閉漫遊時坐原地，僅保留眨眼、呼吸等細微待機動畫，不跑跳。睡覺停止自動位移，仍可手動拖曳。
- 多隻寵物可重疊並依習性互相打鬧，打鬧會吵醒睡覺的寵物；被吵醒後依種類與個性決定加入、避開或繼續睡。關閉漫遊者不參與追逐或跑跳打鬧。
- 正常活動支援跨螢幕並遵守可用工作區邊界；螢幕拔除或配置改變不立即搬回，讓寵物自行跑回。控制窗提供「找回寵物」，手動移回可見螢幕，不改漫遊設定。
## 2. 功能目標與完成條件
- 寵物與控制：五欄設定（名字、種類、喜好、個性、興趣），選用外觀覆寫；每隻寵物的資料與素材獨立。設定能即時生效並在重啟後保留。
- 顯示與移動：200×200 範圍內等比動畫，手動拖曳與明確啟用的自動漫遊，多寵物逐步加入；移動偏好不能因重開控制面板而意外變更。
- 安全整理：只處理授權 root，前台使用 opaque ID；確認綁定目前掃描結果，操作前重驗權限／symlink／檔案變更，並有 journal、隔離收據與還原。預覽、確認及 Domain 成功狀態都不能代替真實 OS 結果。
- 後續能力：記憶／回想／複習／提醒、RAG／MCP／Agent、備份／還原、安裝包與簽章更新；更新由啟動或手動檢查觸發。

一個後台控制窗管理多隻寵物，各出籠寵物有獨立原生生活窗，不採放大同一張混合頁面的方式。前台寵物保留 200×200 等比動畫、拖曳、漫遊與右鍵入口；後台控制視窗承載六區功能並可縮放／捲動。關閉控制視窗後寵物繼續運作，反覆開啟只聚焦既有視窗，透過後端 snapshot／事件同步。原單視窗放大修正檔不採用，未獲授權套用至原始碼；雙視窗骨架已在目前來源存在；以下仍為完整功能目標，驗收狀態以上方目前證據為準。Day15／Day16 原文不改。
寵物視窗與控制視窗分工：寵物視窗保留 200×200 等比動畫、拖曳與右鍵入口；控制視窗使用 Leptos，可調整大小並可捲動，不把掃描結果、設定表單與所有按鈕堆進寵物小視窗。重複開啟只顯示／聚焦既有控制視窗，關閉控制視窗不停止寵物，不建立新寵物。
控制視窗分為六個功能區：
- 互動：狀態、互動／結束／睡覺／醒來、已有聊天入口；漫遊逐隻保存；右鍵「坐下」關閉漫遊；動作速度依種類習性，不提供固定速度設定。
- 設定：五欄與選用外觀；必須能讀回、保存及重啟保留，缺後端時明示未接通。
- 記憶：列表、查詢與管理接既有資料服務；尚無對應 API 時只顯示能力狀態，不放無作用的操作按鈕。
- 檔案：授權狀態 → 掃描／SHA256 → 結果 → 確認／取消 → 操作結果／收據 → 還原。只呈現可用 IPC；預覽確認與真實操作分開，未有操作 IPC 時明示未接通。
- 管理：多寵物、備份／還原及封存；依實作能力逐步接通。
- 更新：版本與啟動／手動檢查，依安裝與簽章更新能力接線。
控制窗依寵物識別同步各生活窗的獨立後端狀態；分頁切換不新增寵物、不自行掃描或觸發檔案動作。掃描、確認、收據與錯誤保留在對應功能區，長結果可換行／捲動且操作按鈕可到達。
驗收包含：控制視窗縮至可用小尺寸及放大、系統縮放、鍵盤焦點與捲動、長清單／錯誤文案、六區切換、反覆開啟不重複建立、關閉後寵物仍運作；專用目錄實測 UI → bridge → Tauri → OS／資料層 → 回應 → 畫面，無後端的功能不得假報成功。雙窗骨架已有實作；上述完整 GUI／IPC／檔案流程仍需後續 Day 分段驗收，Day15／Day16 不修改。
