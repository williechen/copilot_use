# 聊天室註冊與登入修正

本機入口：http://localhost:3001/login 。檢查時正式資料庫沒有已註冊帳號，尚未註冊就登入會回 401；未發現後端註冊／登入失效。此次修正首次使用引導、輸入檢查、狀態碼說明、註冊成功提示，以及 Enter 登入與瀏覽器自動填入的表單處理。後端驗證與安全條件保持原有契約。

來源：04c234ed2fcf4d2473358b623638db80eea92d26。原生 release 建置、嚴格 Clippy 與功能驗證通過，服務已重新載入新版。使用本機獨立測試資料庫，實際瀏覽器完成短密碼拒絕、註冊、重複名稱、錯誤密碼、Enter 登入、重新載入保持登入及登出；正式資料庫沒有新增測試帳號。未執行付費 AI、遠端 CI 或 GitHub 發布。

首次使用請自行填入帳號與至少 12 字元密碼，按「註冊」，成功後按「登入」。請勿提供密碼給代理。

教學規則同步改為：先建立可操作的基本功能，基本流程與相應驗證通過後推進下一功能，再逐步補充細節、條件與例外。阻擋流程、資料安全與必要相依性當步處理；其他深化工作保留在原功能項追蹤。不新增 Day、不變更階段與歷史版號。
