# v0.2.1 控制介面與原生更新修正

驗收來源：`9bcae7c5d139f75ed08b4daffece602a71fdab34`。同一乾淨來源完成原生 release／64項功能 Gate、7項更新安全測試、實際桌面 GUI 及真實簽章更新包套用／竄改拒絕驗證。

- 動作、速度連續變更會依序合併保存並即時生效，不需按保存或重啟。巡行開／關持久化；移除環境變數開關覆蓋。設定載入與編輯不互相覆寫。
- 控制介面分六個頁籤，寵物選擇器共用；切換保留已掛載元件與表單，不建立新寵物。
- 右鍵顯示控制選單，選單開啟暫停移動；控制面板重用同一視窗。關閉控制視窗改為隱藏，可右鍵喚回；結束程式位於選單。
- 使用 [Tauri 官方 single-instance 插件](https://v2.tauri.app/plugin/single-instance/)，再次點啟動入口聚焦既有控制視窗。實際曾觀察兩個舊程序，但資料庫只有一隻小犬；修正後保留相同ID，只有一個正常程序與兩個既有視窗。
- GitHub 更新只在啟動時或按「檢查更新」執行，無週期 timer。來源、簽章、版本、archive／大小／build 身分都驗證後，備份SQLite、切換current並按需重啟；保留原桌面入口與app_data。
- 現有v0.2.0不含原生更新驗證器，本次以已驗證的本機簽章包原地遷移到v0.2.1；未再執行安裝器。未冒稱此包已從GitHub發行／下載。

GitHub目前正式v0.1.0，比本機舊；實際檢查成功並略過降版。新版原生更新資產已備妥，後續正式Release需上傳兩份簽章更新資產，見docs/GITHUB_PET_UPDATES.md。未發布新Release、未改寫v0.1.0舊驗收與v0.2.0標記，未聲稱新版遠端CI／Windows／macOS／付費AI已重新驗證。

早期GUI回歸曾捕捉動作／速度快速連續選取時，第二次事件因busy而被忽略；已改為序列合併保存，最終GUI實際介面檢查通過。
