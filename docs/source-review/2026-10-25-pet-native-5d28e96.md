## 缺口與後續調整

1. 重啟恢復：pet_server/src/lib.rs 的 setup 只取 store.active()，而 PetStore::active 依 local_pet_selection 的 slot=1 讀單隻。本輪真實結果與此一致。應接回原有「逐筆恢復所有未回籠寵物」項；三筆資料仍在，問題是視窗恢復接線，不是 DB 寫入遺失。
2. 漫遊：roam.rs 固定查 label `pet`，實際 pet_windows::open 建立 `pet-{UUID.simple()}`。應以真實逐 ID 生活窗與生命週期接回，不以固定 label 單測結案。
3. 顯示可讀性：透明生活窗疊在淺色控制台上時，白字及陰影的對比不足。09:29:19 截圖已見三窗，不能再描述為全部空白；保留背景、文字對比與重疊時可讀性的 UI 調整項。

原生視窗關閉失敗的補償注入、跨平台原生 build／安裝更新、單幀單圖 FIFO、真實清理／receipt／restore 等未在本輪驗證，不因此結案。未新增 Day、未修改教學原文／雜湊、next_day、FIFO 或 last_full_comparison。
